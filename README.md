# assignment2-vehicle-system
In Assignment 2, I created a Vehicle Management System that works with three types of transport: Car, Motorcycle, and Truck
Each vehicle has a driver, and all vehicles are stored in an array
The program has an abstract class called Vehicle. It contains common information like brand and year
Car, Motorcycle, and Truck are child classes of Vehicle. They inherit its properties and methods and have their own behavior
There is also a Driver class. A vehicle has a driver, and one driver can drive more than one vehicle
